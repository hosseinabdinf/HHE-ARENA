# Agent Instructions

Before working on this project, read the files in the `agent/` directory:

1. `agent/RULES.md` for working rules and constraints.
2. `agent/Structure.md` for the repository layout and ownership boundaries.
3. `agent/Track.md` for current tasks, priorities, and progress.
4. `agent/Memory.md` for durable project context and prior decisions.

Keep these files accurate as the project evolves. Update `Track.md` when task
status changes, `Memory.md` when a durable decision or lesson is established,
and `Structure.md` when the repository layout changes.

Important: Keep the conversation with user as compact as possible, only give very important information.
